Projects

InjectLab Ongoing

A Python research testbed measuring indirect prompt injection attacks against tool-using LLM agents (simulated email, web, and calendar tasks) running local open models (Qwen2.5, Llama3.1) via Ollama, following the AgentDojo research framework at a smaller experimental scale.

Measures task utility, utility-under-attack, and attack success rate via deterministic world-state checkers rather than LLM-judge evaluation; implements defenses including spotlighting, sandwiching, tool filtering, and a classifier-based injection detector.
